在真实视频中测试

  1. 执行 npm run build，在 Chrome 的扩展程序页面加载 dist。
  2. 打开 Tranlithion 设置，保存 API Key 并授权对应服务域名。
  3. 打开带日文字幕的 YouTube 视频并开启 CC；扩展会优先读取字幕轨道，再回退到 YouTube 显示字幕。

仅处理网页可访问的文本字幕；烧录字幕 OCR、标签页音频捕获与实时 ASR 属于后续版本。
